# Security Policy

## Supported Versions

This project is currently in active development and tracks the `main` branch.

## Reporting a Vulnerability

Please do not open public issues for suspected vulnerabilities.

1. Email: `security@company.example` (replace with your real alias)
2. Include:
   - Affected commit/tag
   - Reproduction steps
   - Impact assessment
   - Suggested mitigation (if known)
3. You will receive an acknowledgement within 2 business days.

## Disclosure Process

- We triage severity within 5 business days.
- We coordinate a fix and release timeline based on impact.
- We publish a security advisory after remediation.

## Security Baseline

- Dependencies are managed via Dependabot.
- CI must pass before merge.
- Environment validation is required for runtime config.
